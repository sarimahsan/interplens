Topic 1: Core Framework Architecture & Setup

InterpLens is designed as a zero-copy, real-time visual debugger for deep transformer networks. Unlike offline analysis scripts, InterpLens hooks into live PyTorch models running in VRAM and exposes intermediate layer states directly to a interactive web interface.

1.1 Zero-Copy GPU Hook Adapter Architecture

The core engine relies on an abstract HookedTransformerAdapter layer. When you invoke il.launch(model), InterpLens attaches lightweight PyTorch forward hooks (register_forward_hook) to each residual stream block, multi-head self-attention layer, and MLP expansion layer.

  • Zero Weight Copies: Does not duplicate transformer weights in VRAM. It directly inspects existing tensor allocations.
  • Dynamic Hook Activation: Hooks capture intermediate activations ($x_l$, attention weights $A_{h}$, MLP activations $m_l$) strictly during active analysis calls and detach immediately afterward to minimize latency overhead.
  • Universal Model Support: Automatically introspects standard HuggingFace architectures (GPT-2, Qwen2.5, Llama-3, Mistral, Gemma) as well as TransformerLens HookedTransformer instances.

1.2 Installation & Launch Modes

Install the package directly via PyPI:

TERMINAL 
pip install interplens

Choose from three supported execution modes:

Attach to an active PyTorch / TransformerLens model in Python:

import interplens as il
from transformer_lens import HookedTransformer

model = HookedTransformer.from_pretrained("gpt2-small", device="cuda")
il.launch(model=model, port=8501)

Launch directly from command line interface:

interplens launch --model Qwen/Qwen2.5-3B --device cuda --port 8501

Embed as an asynchronous FastAPI microservice:

import uvicorn
from interplens.server.app import app

uvicorn.run(app, host="127.0.0.1", port=8501)

Topic 2: Interpretability Engines & Deep Dives

Detailed breakdown of purpose, mathematical formulation, metrics, and interpretability workflows across all six core modules.

2.1 Logit Lens Engine (Intermediate Vocabulary Projections)

Purpose & Concept

In transformer language models, the residual stream acts as a central highway ($x_0, x_1, \dots, x_L$) where layers read and write information. The Logit Lens engine bypasses late transformer layers by directly projecting intermediate residual stream vectors $x_l$ into vocabulary space via the unembedding matrix $W_U$.

Mathematical Formulation

\text{logits}_l = W_U \cdot \text{LN}(x_l) \quad \in \mathbb{R}^{V}

p_l(v) = \text{softmax}(\text{logits}_l) = \frac{\exp(\text{logits}_l(v))}{\sum_{v'} \exp(\text{logits}_l(v'))}

Key Analytics & Diagnostics

  • Layer $\times$ Position Prediction Grid: Shows the top-1 predicted token string at every layer for every prompt token position. Allows observing exactly where the model resolves facts (e.g. at Layer 14).
  • Probability & Logit Trajectory Curves: Plots confidence $p_l(\text{target})$ across layers to detect sharp prediction phase transitions.
  • Prediction Entropy: Calculates $H(p_l) = -\sum p_l(v) \log p_l(v)$ to measure uncertainty reduction across intermediate blocks.
  • KL Divergence: Computes $D_{KL}(p_L \parallel p_l)$ against final output logits to quantify how close intermediate layers are to the final output state.

2.2 Residual Stream Inspector (Vector Norms & Geometric Drift)

Purpose & Concept

Monitors vector geometry and magnitude growth across the residual stream highway. As layers apply attention updates and MLP additions ($x_{l+1} = x_l + \text{MHSA}_l(x_l) + \text{MLP}_l(x_l)$), residual vector norms grow systematically.

Mathematical Formulation

\text{Norm}_l = \|x_l\|_2 = \sqrt{\sum_{i=1}^{d_{\text{model}}} x_{l,i}^2}

\text{CosSim}(x_i, x_j) = \frac{x_i \cdot x_j}{\|x_i\|_2 \|x_j\|_2}

Key Analytics & Diagnostics

  • Layer L2 Vector Norm Curves: Tracks energy growth across layers to identify layers that make major vector additions.
  • Inter-Layer Cosine Similarity Heatmap ($L \times L$ Matrix): Measures directional alignment between residual representations at layer $i$ and layer $j$. High similarity blocks indicate passive passing of information, while sharp drops highlight transformation blocks.
  • GPU Hardware Profiler Telemetry: Real-time hardware VRAM memory footprint readout and forward pass latency profiling.

2.3 Attention Head Explorer (QKV Routing & Circuit Graphs)

Purpose & Concept

Visualizes how attention heads route information across tokens. Inspects positional bias, induction heads, subject-verb agreement heads, and previous-token heads.

Mathematical Formulation

A_{l,h} = \text{softmax}\left(\frac{Q_{l,h} K_{l,h}^T}{\sqrt{d_k}}\right) \quad \in \mathbb{R}^{N \times N}

Key Analytics & Diagnostics

  • Single-Head Attention Heatmap ($N \times N$ Matrix): Renders exact Query-Key attention weight probabilities between all input token positions.
  • Multi-Head Grid View: Shows small thumbnail heatmaps for all heads in a selected layer simultaneously, enabling fast identification of active heads.
  • HTML5 Canvas Arc Link Visualizer: Draws curved connection links between Query and Key tokens, weighted and colored by attention magnitude.

2.4 Neuron Activation Explorer (MLP Polysemanticity & Attribution)

Purpose & Concept

MLP layers expand the hidden state into a higher dimension (e.g. $d_{\text{mlp}} = 4 \times d_{\text{model}}$) where individual neurons act as key-value memories storing facts and concepts.

Mathematical Formulation

m_l = \text{GELU}(x_l W_{\text{in}} + b_{\text{in}}) \quad \in \mathbb{R}^{d_{\text{mlp}}}

Key Analytics & Diagnostics

  • Top-$K$ Firing Neurons Ranking: Filters and sorts the highest firing intermediate MLP neurons at any selected token position.
  • Prompt Text Lighting Strip: Highlights prompt tokens in green with background opacity scaled proportionally to the activation magnitude of a selected single neuron.
  • Input Token Attribution (Attention Rollout): Multiplies attention matrices across layers to compute total token influence flow from input to output.

2.5 Automated Causal Interventions & ROME Causal Tracing

Purpose & Concept

Moves beyond passive observation to active causal experimentation (ROME-style causal tracing). InterpLens runs clean vs. corrupted forward passes, patches individual intermediate residual vectors $h_{l,p}^{\text{clean}}$ into corrupted runs, and measures causal recovery of the target prediction.

Mathematical Recovery Formula

\text{LogitDiff} = \text{logit}(y_{\text{target}}) - \text{logit}(y_{\text{corrupt\_target}})

\text{Recovery \%} = \frac{\text{LogitDiff}_{\text{patched}} - \text{LogitDiff}_{\text{corrupt}}}{\text{LogitDiff}_{\text{clean}} - \text{LogitDiff}_{\text{corrupt}}} \times 100\%

Key Analytics & Diagnostics

  • Clean vs. Corrupt Prompt Workbench: Allows specifying target clean prompts (e.g. "The Eiffel Tower is in") and corrupted control prompts (e.g. "The Colosseum is in").
  • $N_{\text{layers}} \times N_{\text{pos}}$ Causal Recovery Heatmap: Full grid sweep showing exact causal recovery percentages for every single layer and token position. Identifies factual storage loci (e.g. Subject token at mid-layers).
  • Single-Cell Intervention Drilldown: Click any heatmap cell to view exact token strings, patched baseline logit differences, and recovery stats.

2.6 Model Architecture Topology & Parameter Breakdown

Purpose & Concept

Introspects PyTorch model parameters (model.named_parameters()) to classify and compute exact parameter budget shares across architectural components.

Classification Categories

  • MLP Expansion Sublayers: Linear gate, up, and down projection weights.
  • Multi-Head Self-Attention (MHSA): Query, Key, Value, and Output projection matrices ($W_Q, W_K, W_V, W_O$).
  • Embeddings: Token and positional embedding tables ($W_E$).
  • Language Model Head: Unembedding classification head ($W_U$).
  • LayerNorms: Pre-block and post-block normalization gains and biases ($\gamma, \beta$).

Topic 3: Python API & REST Endpoints Specification

3.1 Programmatic Execution API

Python API 
import interplens as il
from interplens.analysis.causal_patching import run_causal_patching_sweep

# 1. Launch debugger GUI
il.launch(model=model, port=8501)

# 2. Run causal sweep programmatically
results = run_causal_patching_sweep(
    adapter=adapter,
    clean_prompt="The Eiffel Tower is in",
    corrupt_prompt="The Colosseum is in",
    target_token_str="Paris"
)

print(f"Max Recovery: {results.max_recovery_percentage}% at Layer L{results.max_recovery_layer}")

3.2 FastAPI REST Service Endpoints

Method Endpoint Description
POST /api/run Executes model forward pass and caches intermediate activation tensors.
GET /api/analysis/logit-lens Returns layer-by-layer Top-K logit lens token predictions & probabilities.
GET /api/analysis/residual-stream Returns residual L2 vector norms and inter-layer Cosine Similarity matrix.
GET /api/analysis/attention Returns single-head attention matrix, multi-head grid, and arc diagram links.
GET /api/analysis/neurons Ranks top-K firing MLP neurons and single neuron prompt text lighting strips.
POST /api/analysis/causal-patching Runs clean vs corrupt activation patching sweep and returns $N_{\text{layers}} \times N_{\text{pos}}$ recovery matrix.
GET /api/model/topology Inspects PyTorch parameter tensors and builds component parameter breakdown payload.

  • Mistral Family: Mistral-7B-v0.1, Instruct
  • Gemma Family: Google Gemma-2B, Gemma-7B
  • EleutherAI Pythia Family: Pythia 70M, 160M, 410M, 1B, 2.8B, 6.9B, 12B
