The Visual Debugger for LLM Internals

InterpLens is a production-grade mechanistic interpretability toolkit and visual workbench for PyTorch and TransformerLens. Inspect intermediate vocabulary projections, trace causal circuits, compute induction head metrics, steer representations, and introspect attention graphs in real time with zero-copy GPU memory attachment.

Installation Options

Install InterpLens directly from PyPI using your preferred package manager.

BASH 
# Standard installation (PyTorch, FastAPI, UI Debugger)
pip install interplens

# Full bundle (TransformerLens + Scikit-Learn PCA support)
pip install interplens[all]
BASH 
uv pip install interplens[all]
BASH 
poetry add interplens --extras "all"

Target specific optional dependencies based on your environment:

  • interplens[tl]: Adds transformer-lens>=2.0.0 for HookedTransformer support.
  • interplens[analysis]: Adds scikit-learn>=1.2.0 for high-dimensional PCA residual trajectory calculations.
  • interplens[all]: Installs all optional engines and dependencies.
  • interplens[dev]: Installs testing dependencies (pytest, pytest-asyncio).

Configuration & Environment Variables

Fine-tune server behavior, compute devices, and memory settings via environment variables.

Variable Default Type Description & Fallback Behavior
INTERPLENS_PORT 8000 int HTTP server port. Automatically falls back to 8000 if invalid integer string is passed.
INTERPLENS_HOST 127.0.0.1 str Host binding IP. Automatically switches to 0.0.0.0 when Google Colab is detected.
INTERPLENS_DEVICE auto str Compute target (cuda, cpu, mps, auto). Falls back to cpu if CUDA is requested but unavailable.
INTERPLENS_MAX_SESSIONS 3 int Maximum number of cached activation sessions in memory before LRU eviction.
INTERPLENS_FP16 true bool Whether to use half-precision (float16) when loading HuggingFace models on GPU to conserve VRAM.
INTERPLENS_DEBUG false bool Enables verbose diagnostic logging across adapters and analysis modules.

Recipe 1: Zero-Copy GPU Memory Attachment

Attach InterpLens to an already-loaded TransformerLens model without reloading

If your model is already loaded in CUDA memory (e.g. inside a research script), pass the instance directly to il.launch(). InterpLens wraps the model in-place with zero memory duplication:

PYTHON 
import interplens as il
from transformer_lens import HookedTransformer

# 1. Suppose your model is already loaded in GPU memory:
model = HookedTransformer.from_pretrained("gpt2-small", device="cuda")

# 2. Attach visual debugger backend (runs in background thread by default)
adapter = il.launch(model=model, port=8000)

print(f"Debugger active at: http://127.0.0.1:8000")
print(f"Model: {adapter.model_name} | Layers: {adapter.num_layers} | Hidden Dim: {adapter.hidden_dim}")

# 3. Stop the background server whenever you are finished:
# il.stop_server()

Recipe 4: Custom PyTorch `nn.Module` with `PyTorchAutoHooker`

Hook into proprietary or research transformer architectures

When passing a novel `nn.Module` without TransformerLens, set `auto_hook=True` to let `PyTorchAutoHooker` discover internal residual streams and attention layers:

PYTHON 
import torch
import torch.nn as nn
import interplens as il
from transformers import AutoTokenizer

# Your custom PyTorch transformer class
class CustomTransformer(nn.Module):
    def __init__(self):
        super().__init__()
        self.embed = nn.Embedding(50257, 256)
        self.layers = nn.ModuleList([
            nn.TransformerEncoderLayer(d_model=256, nhead=4, batch_first=True)
            for _ in range(4)
        ])
        self.ln_f = nn.LayerNorm(256)
        self.lm_head = nn.Linear(256, 50257, bias=False)

    def forward(self, input_ids, **kwargs):
        x = self.embed(input_ids)
        for layer in self.layers:
            x = layer(x)
        x = self.ln_f(x)
        return self.lm_head(x)

# Instantiate custom model and tokenizer
my_model = CustomTransformer().eval()
tokenizer = AutoTokenizer.from_pretrained("gpt2")

# Launch visual debugger with automated hook discovery
adapter = il.launch(model=my_model, tokenizer=tokenizer, auto_hook=True, port=8000)

Recipe 6: Programmatic Activation Steering

Inject direction vectors to shift internal model representations

PYTHON 
import interplens as il
from interplens.adapters import get_adapter_for_model
from interplens.analysis import apply_activation_steering

adapter = get_adapter_for_model("gpt2", device="cuda")
adapter.load()

# Inject steering vector at layer 6 with multiplier 2.5
steered_result = apply_activation_steering(
    adapter=adapter,
    prompt="Love and compassion are",
    target_layer=6,
    multiplier=2.5,
    steering_vector=None  # Computes synthetic steering if None, or pass List[float]
)

print("Original Top-1 Prediction:", steered_result.original_prediction)
print("Steered Top-1 Prediction:", steered_result.steered_prediction)
print("Shift Cosine Distance:", steered_result.cosine_distance)

Recipe 9: Custom Architecture Strategy Plugin

Register custom hook mapping rules for proprietary research architectures

PYTHON 
from interplens.adapters import (
    BaseArchitectureStrategy,
    ArchitectureFamily,
    register_architecture_strategy,
    get_adapter_for_model
)

class MyCustomMoEStrategy(BaseArchitectureStrategy):
    family = ArchitectureFamily.CUSTOM
    
    def matches(self, model_or_name) -> bool:
        # Match models with 'my-custom-moe' in name or class
        return "custom-moe" in str(getattr(model_or_name, "__name__", model_or_name)).lower()

    def get_layer_count(self, model) -> int:
        return len(model.custom_blocks)

    def get_hidden_dim(self, model) -> int:
        return model.config.d_model

    def get_head_count(self, model) -> int:
        return model.config.n_heads

    def get_residual_hook_names(self, model):
        return [f"custom_blocks.{i}.post_residual" for i in range(len(model.custom_blocks))]

# Register strategy into global registry
register_architecture_strategy(MyCustomMoEStrategy())

# InterpLens will now automatically use this strategy for any custom-moe model
adapter = get_adapter_for_model("my-custom-moe-7b")

Robustness & Fail-Safe Fallbacks Matrix

How InterpLens prevents crashes across non-standard architectures, invalid inputs, and memory constraints.

Subsystem Potential Failure Condition InterpLens Fallback Mechanism Resulting Behavior
Model Loading FlashAttention / SDPA unsupported on CPU / device 3-Stage Fallback: (1) eager attention → (2) default attention → (3) patched config Model loads safely without C-extension errors
Dependency Loading transformer-lens not installed in environment Fast find_spec check in get_adapter_for_model falls back to HuggingFace AutoModel Loads without requiring heavy optional dependencies
Tokenizer Missing Bare PyTorch model without a tokenizer object Converts prompt strings to ASCII integer token tensors or float vectors Forward pass executes and activations are captured
Vocabulary Unembed Model lacks linear unembedding matrix $W_U$ Raises UnembeddingNotFoundError and disables Logit Lens while keeping Residual/Attention active Graceful capability degradation (L3 instead of L2)
Attention Division Zero token distance in synthetic attention calculations Guarded by max(1, i - j) in diagonal decay functions Prevents ZeroDivisionError
Causal Target Decoding Target token decode failure or out-of-vocab token 3-Tier Decode: (1) adapter.decode() → (2) tokenizer.decode() → (3) fallback string Causal sweep completes with exact token label
Cross-Device Patching Vector norm difference between CPU and CUDA tensors Explicit .detach().cpu() before torch.norm calculation Prevents PyTorch device mismatch exceptions
Session Concurrency Model forward pass raises runtime CUDA out-of-memory Forward pass executes before LRU cache eviction Existing valid cached sessions are preserved
Config Parsing Invalid environment variable string in INTERPLENS_PORT Safe _get_env_int helper catches (ValueError, TypeError) and returns default 8000 Server starts reliably without import-time crash
Colab Execution Default 127.0.0.1 localhost binding unreachable in Colab Detects google.colab and switches host to 0.0.0.0 + calls kernel port proxy Seamless remote web UI access in cloud notebook

Core Interpretability Engines Deep-Dive

Mathematical formulations, telemetry diagnostics, and visual analytics for transformer networks.

1. Logit Lens Engine & Entropy Dynamics

Intermediate Vocabulary Projections & Phase Transition Tracking

The residual stream serves as a shared memory highway. The Logit Lens projects intermediate vectors $x_l$ into vocabulary space by applying the unembedding matrix $W_U$:

$$\text{logits}_l = W_U \cdot \text{LN}_{\text{final}}(x_l) \quad \in \mathbb{R}^{V}$$ $$p_l(v) = \text{softmax}(\text{logits}_l) = \frac{\exp(\text{logits}_l(v))}{\sum_{v'} \exp(\text{logits}_l(v'))}$$ $$H(p_l) = -\sum_{v} p_l(v) \log p_l(v) \quad \text{[Prediction Uncertainty / Entropy]}$$ $$D_{KL}(p_L \parallel p_l) = \sum_{v} p_L(v) \log\left(\frac{p_L(v)}{p_l(v)}\right) \quad \text{[KL Divergence to Output]}$$

2. Residual Stream Inspector & Activation Steering

Energy Growth, Inter-Layer Drift & Continuous Representation Steering

$$\|x_l\|_2 = \sqrt{\sum_{i=1}^{d_{\text{model}}} x_{l,i}^2} \quad \text{[L2 Vector Energy Norm]}$$ $$\text{CosSim}(x_i, x_j) = \frac{x_i \cdot x_j}{\|x_i\|_2 \|x_j\|_2} \quad \text{[Inter-Layer Alignment Matrix]}$$ $$x_l^{\text{steered}} = x_l + \alpha \cdot \vec{v}_{\text{steering}} \quad \text{[Continuous Activation Injection]}$$

3. Attention Head Explorer & Induction Detector

QKV Routing Patterns, Arc Link Visualizer & Induction Head Scans

$$A_{l,h} = \text{softmax}\left(\frac{Q_{l,h} K_{l,h}^T}{\sqrt{d_k}}\right) \quad \in \mathbb{R}^{N \times N}$$ $$\text{Score}_{\text{induction}}(l, h) = \frac{1}{M} \sum_{i} A_{l,h}(p_i, p_i - \Delta + 1)$$

4. MLP Neuron Explorer & Token Attribution

Key-Value Factual Neurons, Text Lighting Strips & Attention Rollout

$$m_l = \text{GELU}(x_l W_{\text{in}} + b_{\text{in}}) \quad \in \mathbb{R}^{d_{\text{mlp}}}$$ $$R = \prod_{l=1}^{L} \left(0.5 A_l + 0.5 I\right) \quad \text{[Attention Rollout Flow Matrix]}$$

5. Automated Causal Patching & ROME Sweeps

Clean vs Corrupt Activation Swaps & Loci of Factual Associations

$$\text{LogitDiff} = \text{logit}(y_{\text{clean}}) - \text{logit}(y_{\text{corrupt}})$$ $$\text{Recovery \%} = \frac{\text{LogitDiff}_{\text{patched}} - \text{LogitDiff}_{\text{corrupt}}}{\text{LogitDiff}_{\text{clean}} - \text{LogitDiff}_{\text{corrupt}}} \times 100\%$$

6. Architecture Topology & Parameter Shares

Parameter Distribution across Attention, MLP, Embeddings & LM Head

Introspects model parameter tensors to calculate exact parameter budgets across MLP Expansion, Self-Attention QKVO, Embeddings ($W_E$), Language Model Head ($W_U$), and Normalization layers.

FastAPI REST & WebSocket Endpoints

HTTP API specification for programmatic integrations, dashboards, and automated analysis jobs.

Method Endpoint Parameters / Body Description
GET /api/health None Health check returning active model name, device, and cached sessions.
POST /api/run {"prompt": str, "corrupted_prompt": Optional[str]} Executes forward pass, stores activations in LRU session store, and returns session ID & token list.
GET /api/analysis/logit-lens session_id, position (int), top_k (int) Returns layer-by-layer predicted tokens, probabilities, entropy, and KL divergence.
GET /api/analysis/residual-stream session_id, position (int) Returns L2 vector norms curve and $L \times L$ Cosine similarity matrix.
GET /api/analysis/attention session_id, layer (int), head (int) Returns single-head $N \times N$ attention matrix, multi-head layer grid, and arc link connection lists.
GET /api/analysis/neurons session_id, layer (int), position (int) Returns top-10 firing MLP neurons and prompt text lighting activation strips.
GET /api/analysis/attribution session_id, target_position (int) Returns input prompt token attribution scores computed via Attention Rollout.
POST /api/analysis/causal-patching {"clean_prompt": str, "corrupt_prompt": str, "target_token": str} Executes ROME causal tracing sweep and returns $N_{\text{layers}} \times N_{\text{pos}}$ recovery heatmap.
POST /api/analysis/steer {"prompt": str, "target_layer": int, "multiplier": float} Injects activation steering vector and returns original vs steered logits and predictions.
GET /api/model/report None Returns comprehensive model discovery report and evaluated capability levels.
GET /api/model/topology None Inspects model parameter tensors and returns percentage breakdown by architectural component.
GET /api/report/pdf session_id Generates and downloads publication-ready PDF diagnostic report.
WS /api/ws/telemetry WebSocket Connection Real-time streaming telemetry push (VRAM allocated/reserved, session count, device status).

Exception Hierarchy Reference

Structured exceptions defined under interplens.exceptions for robust error handling.

PYTHON EXCEPTION TREE 
InterpLensError (Base exception for all InterpLens errors)
├── ModelLoadError            # Raised when model weights or tokenizer fails to load
├── AdapterNotFoundError       # Raised when no suitable adapter strategy can be resolved
├── CapabilityError           # Raised when model lacks required interpretability capability
│   └── UnembeddingNotFoundError  # Raised when unembedding matrix W_U is absent or inaccessible
└── ServerExecutionError      # Raised when the debugger web server encounters a runtime fault

Example of structured error handling in production code:

PYTHON 
import interplens as il
from interplens.exceptions import ModelLoadError, UnembeddingNotFoundError

try:
    adapter = il.launch(model_name="nonexistent-model-id")
except ModelLoadError as e:
    print(f"Caught model load failure: {e}")
except UnembeddingNotFoundError as e:
    print(f"Model lacks W_U unembedding: {e}")
